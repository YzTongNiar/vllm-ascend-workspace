# 本地工具目录

中文 | [English](README.md)

本目录用于存放自行安装和独立维护的工具与技能（skill）仓库。

| 示例仓库 | 用途 |
|---|---|
| `benchmark` | 模型精度与服务性能评测 |
| `aisbench_auto_tools` | AISBench 负载与实验辅助工具 |
| `cannbot-skills` | CANN 开发与优化技能 |
| `vllm-ascend-skills` | vLLM Ascend 开发、验证、调试与分析技能 |

按任务需要选择仓库与版本。使用前请阅读各已安装项目的 README 了解安装与依赖，修改代码前请阅读其适用的 AGENTS.md。使用某个技能时，请阅读其 SKILL.md 及相关资源。

代码与文档变更请在对应所属仓库中维护。调用方配置实际安装路径；当工具版本影响结果复现时，请记录所用工具版本。
