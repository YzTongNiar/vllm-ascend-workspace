# Task record example

[中文](README.zh.md) | English

`task.json` provides a small editable task record. Add or remove fields to suit the work.

For a task that spans sessions, useful notes include its goal, selected source revisions, completed work, commands and evidence locations, unresolved questions, and the next action. Describe what was verified and what remains to be checked so another session can resume the work.

Task notes can use plain Markdown. When using MindIE task packages, use the selected tool's native records export format. Experiment outputs can retain original receipts, logs, and artifacts alongside a short explanation of the result.
