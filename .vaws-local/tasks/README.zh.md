# 任务数据

中文 | [English](README.md)

本目录存放任务记录、实验输出及相关文件。单个任务可参考以下结构组织：

```text
<task-id>/
├── task.json                  # 任务目标、源码版本引用与任务元数据
├── records/                   # 进展、结论与交接说明
└── runs/
    └── <run-id>/               # 命令、执行回执、日志、指标与产物
```

对于需要跨会话接续的工作，建议简短记录任务目标、已完成工作、证据位置、未决问题和下一步动作。记录解释实验结果所需的源码版本与执行命令，并明确区分已观察到的事实与后续计划。

按任务需要选择记录字段和运行产物内容。使用 MindIE 工具时，可按需保留其原生导出的记录与执行回执；仅针对实际执行的操作生成文件。
