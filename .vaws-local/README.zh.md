# 本地持久化数据

中文 | [English](README.md)

本目录存放本地记录、临时数据以及需要保留的结果。以下目录结构仅供参考；请按实际工作需要创建目录并调整内容。

```text
.vaws-local/
├── tasks/
│   └── <task-id>/
│       ├── task.json           # 任务元数据
│       ├── records/            # 开发笔记与证据摘要
│       └── runs/
│           └── <run-id>/       # 单次实验或执行的输出产物
├── machines/                  # 本地机器登记与连接参考信息
├── shared/                    # 跨任务共享的资料与数据集
├── cache/                     # 可重建或可重新下载的缓存数据
└── archives/                  # 归档的任务数据、快照与历史输出
```

请根据数据用途选择存储格式和保留策略。将可复用的共享数据与单次运行输出分开存放，并区分可重新生成的缓存数据。目录说明文档与 Git 忽略规则受版本控制，个人数据内容仅保留在本地。
